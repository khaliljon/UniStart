# Adaptive SAT/TOEFL/NUET Preparation Platform

## Purpose
Web application to provide adaptive learning and recommendations for standardized tests:
- SAT
- TOEFL
- NUET
- future UNT reforms

## Tech Stack
- Backend: .NET 8 (ASP.NET Core)
- Frontend: React 19 + TypeScript
- Database: PostgreSQL 17
- Authentication: JWT
- Hosting: Docker / Kubernetes

## Features
- User management (students, tutors, admins)
- Adaptive testing engine
- Skills tracking and analytics
- Multi-exam support
