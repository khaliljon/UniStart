## Слайд 2 — Введение

Процесс подготовки к международным экзаменам (SAT, TOEFL, IELTS, NUET, CSCA) требует персонализированного подхода, учитывающего индивидуальный уровень знаний каждого учащегося. Существующие онлайн-платформы предлагают статичный набор тестов одинаковой сложности для всех пользователей, что снижает эффективность подготовки.

UniStart -- это веб-платформа адаптивной подготовки к международным экзаменам, использующая математические модели психометрии (Item Response Theory, 3PL-модель) и алгоритм компьютерного адаптивного тестирования (CAT) для динамического подбора вопросов под уровень каждого ученика.

Платформа развернута в продакшн-среде на домене **unistart.kz** и является официальным партнером **LinHao International School** по подготовке к экзамену CSCA.

## Слайд 9 — Математическая модель: IRT 3PL

### Модель Item Response Theory (3 Parameter Logistic)

Вероятность правильного ответа ученика с уровнем способности θ на вопрос:

$$P(\theta) = c + (1 - c) \cdot \frac{1}{1 + e^{-a(\theta - b)}}$$

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| θ (тета) | Уровень способности ученика | [-4, +4] |
| a | Дискриминация вопроса (различающая способность) | 0.5 - 2.5 |
| b | Сложность вопроса | -3.0 - +3.0 |
| c | Вероятность угадывания | 0.0 - 0.35 (по умолчанию 0.25) |

### Оценка способности — метод EAP (Expected A Posteriori)
- Байесовское численное интегрирование
- 81 квадратурная точка на отрезке θ ∈ [-5, +5]
- Априорное распределение: N(μ=0, σ=1.5)
- Пересчет θ по всем ответам ученика при каждом новом ответе
- Результат: (θ, SE) — оценка с доверительным интервалом 95%: θ ± 1.96 * SE

## Слайд 10 — Алгоритм CAT (компьютерное адаптивное тестирование)

### Критерий Фишера для выбора следующего вопроса

$$I(\theta) = \frac{a^2 (P - c)^2 (1 - P)}{(1 - c)^2 \cdot P}$$

Алгоритм выбирает вопрос с максимальной информацией при текущей оценке θ ученика.

### Стратегия выбора
1. Вычислить информацию Фишера для каждого неотвеченного вопроса
2. Из вопросов с информацией >= 70% от максимальной — выбрать случайный (контроль экспозиции)
3. Если пул вопросов исчерпан — рециклинг ранее отвеченных (кроме освоенных)

### Кривая забывания Эббингауза (интервальное повторение)

$$R(t) = e^{-t/S}, \quad S = S_0 \cdot (1 + f)^n$$

Где S — стабильность памяти, n — количество успешных повторений, f = 1.5.
Вопросы с низкой вероятностью удержания в памяти предлагаются первыми.

## Слайд 11 — Прогнозирование баллов

### Маппинг θ в баллы экзамена

$$\text{Score} = \text{MinScore} + \frac{\theta - \theta_{min}}{\theta_{max} - \theta_{min}} \cdot (\text{MaxScore} - \text{MinScore})$$

Где θ_min = -3, θ_max = 3. Расчет ведется для каждой секции экзамена отдельно.

### Возможности модуля прогнозирования
- Посекционный прогноз с 90% доверительным интервалом (θ ± 1.645 * SE)
- Категоризация: сильная (θ >= 1), средняя (>= 0), слабая (>= -1), критическая (< -1)
- What-If сценарии: "Если я подтяну тему X до уровня Y, какой будет общий балл?"
- Ранжирование тем по ROI: максимальный прирост балла при минимальных усилиях
- История прогнозов для отслеживания прогресса

## Слайд 12 — Адаптивный учебный план

### Алгоритм генерации (3 прохода)

**Проход 1 — Основные сессии:**
Топологическая сортировка тем (алгоритм Кана) с учетом зависимостей.
Приоритет = 3.0 - θ (слабые темы в первую очередь).
Ограничение: 30-120 минут в день.

**Проход 2 — Интервальное повторение:**
Повторения через [1, 3, 7, 14, 30] дней.
Повторение пропускается, если удержание R(t) >= 0.8 (кривая Эббингауза).

**Проход 3 — Заполнение пробелов:**
Дни с нагрузкой менее 30 минут дополняются практикой по слабым темам (θ < -0.5).

### Типы записей плана
| Тип | Минуты | Вопросов |
|-----|--------|----------|
| Слабость (Weakness) | 30 (x1.5) | до 10 |
| Новая тема (New) | 20 | до 7 |
| Практика (Practice) | 15 | до 5 |
| Повторение (Review) | 10 | до 3 |

### Адаптивная перебалансировка
- Сильные темы (точность >= 80%): лишние повторения удаляются
- Слабые темы (точность < 50%): добавляются дополнительные сессии

## Слайд 17 — White-Label система

### Поддомены для тьюторских школ

Каждая тьюторская школа может работать под собственным брендом:

| Параметр | Пример |
|----------|--------|
| Поддомен | linhao.unistart.kz |
| Кастомный домен | prep.linhao.cn |
| Цвет интерфейса | #DC2626 (красный LinHao) |
| Логотип | Собственный URL |
| Заголовок навбара | LinHao Prep |
| Специализации школы | CSCA, SAT |

### Технический механизм
1. При регистрации с поддомена — ученик автоматически привязывается к школе
2. Брендинг загружается через API: `GET /api/tutors/schools/branding?slug=X`
3. React-контекст `BrandingContext` применяет CSS-переменные для цветов и логотипа
4. Тьюторы школы видят только специализации, разрешенные школой
5. SchoolAdmin управляет: учениками, тьюторами, заявками, специализациями
